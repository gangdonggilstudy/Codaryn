# Codaryn 개발 문서

Codaryn의 범용 작업 엔진, CLI 우선 설계, 코딩과 자기 개발 루프, 민감정보 처리, 검증과 협업 절차를 관리한다. 사용자가 제품 방향을 정하고 Codex가 최종 기술 판단과 개발 관리를 맡는다. 코딩과 토큰 사용이 많은 작업은 전문 페르소나를 지정한 Claude에 배정한다.

## 문서 적용 원칙

사용자의 최신 지시가 문서에 우선한다. 확정된 요구와 관리자 판단, 아직 결정하지 않은 항목을 구분해 기록한다. 문서가 충돌하면 임의로 구현하지 말고 Codex가 해결한다.

코드가 없는 단계의 검증은 문서와 Git 작업 분리 상태를 확인하는 것이다. 실제 API 검증은 로컬 자격증명과 모델 설정이 준비된 후 수행하고, 모의 응답 테스트와 구분한다.
