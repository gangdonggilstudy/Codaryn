## 표기 규칙

- 근거: [실행]은 직접 실행한 결과, [코드]는 코드를 읽어 확인한 것, [추정]은 확인하지 않은 것이다.
- 상태: [구현]은 main에 있는 것, [설계]는 결정만 된 것(예: `models`, Y-1~Y-5), [제안]은 이 폴더의 안이다.
- 출처: 사용자 확정 요구, PM 설계 선택, 미정(O-5 GUI 형태, O-6 VS Code 연동)을 구분해 적는다.
- 출력 예시는 문구 초안이다. 실제 문구는 구현 때 고정 문구 카탈로그로 정한다.
