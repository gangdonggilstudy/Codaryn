# CLI 사용성 검토

- 기준: main `349726a`. Windows 11, Node 26.13. 2026-11-12에 처음 쓰는 사람의 관점으로 실제로 실행했다.
- 범위: 키 없이 할 수 있는 것만 했다.
  - 실행한 명령: `--help`, `doctor`, 설정·task 오류, 키 없는 간편 형식, scripted 예시 실행, `report`, `revert`.
  - 실제 API는 호출하지 않았다.
- 표기:
  - 근거: [실행]은 직접 돌려 본 결과, [코드]는 코드를 읽어 확인한 것, [추정]은 확인하지 않은 것이다.
  - 상태: [구현]은 main에 있는 것, [설계]는 결정만 된 것, [제안]은 이 문서의 개선안이다.
- 심각도:
  - 높음: 첫 실행을 막거나 잘못 판단하게 만든다.
  - 중간: 여러 번 시도하게 만든다.
  - 낮음: 불편하다.
- 우선순위: P0은 투입 전에 고친다. P1은 다음 묶음, P2는 여유가 있을 때 한다.

## 1. 요약

- **잘 된 점**:
  - `doctor`는 항목별로 ok·fail·skipped를 보여 주고, 네트워크·쓰기가 없다고 밝힌다.
  - 키를 파일에 넣거나(`key_in_file`), 작업 공간을 설치 위치로 주거나(`workspace_is_install_dir`), task 파일을 작업 공간 안에 두면 문구가 이유와 대처를 함께 말한다.
  - `report`는 사람이 읽을 Markdown이다. 검사하지 않은 범위도 적는다.
  - 진행 줄이 실행 중에 나온다.
- **가장 큰 문제**:
  1. 사용자 문서가 구현된 단계 3 명령(`doctor`, `report`, `--quiet`, `npm link`)을 다루지 않는다(R-1).
  2. 설정 파일·키·모델이 없을 때 무엇을 어떻게 해야 하는지 문구가 알려 주지 않는다(R-2~R-4).
  3. 모델 ID를 외워 쳐야 하고, 자리표시자가 그대로 통과한다(R-3).
  4. 모든 출력이 영어이고 오류는 JSON 한 줄뿐이다(R-5, R-6).

## 3. 개선안과 기존 결정의 충돌 검토

## 4. 우선순위

- **P0**(투입 전):
  - R-1 문서 갱신.
  - R-2·R-4 설정·키 없음 문구.
  - R-3 자리표시자 거부와 `models` 구현(Y-1~Y-5).

  - A1 `init`, A2 또는 D-1 대안.

  - A9 데모.
  - R-7 오류 위치.

## 5. 결정 필요

| ID | 질문 | 권고 |
| --- | --- | --- |
| D-1 | 매번 `--config`를 주지 않는 방법 | **(a) C-3 개정**을 권한다. 작업 공간 밖 고정 위치 한 곳만 자동으로 읽는다(Windows `%APPDATA%\Codaryn\config.json`, POSIX `$XDG_CONFIG_HOME/codaryn/config.json`). 우선순위는 `--config` > `CODARYN_CONFIG` > 기본 위치. 작업 공간 안이면 S-1로 거부하고, 사용 사실을 진행 줄에 적는다. 작업 공간 안 자동 탐색 금지는 유지한다 |
| D-2 | `init`의 범위 | 키는 받지 않는다. 터미널에서만 묻는다. 모델은 `models` 구현 뒤 연결하고, 그 전에는 자리표시자를 남기고 `doctor`가 표시한다 |
| D-3 | 메시지 언어 | `CODARYN_LANG`(ko·en)과 설정 `language`로 고른다. 없으면 OS 표시 언어가 한국어일 때 ko, 아니면 en으로 한다. 코드·JSON은 영어로 고정한다 |
| D-4 | 키 보관 편의 | 자동 키 파일 로드는 하지 않는다. `init`과 `doctor`가 사용자 환경 변수 등록 명령을 안내한다. `varsFile` 설정 필드는 보류한다 |
| D-5 | 실행 중 권한 확인(A12) | 단계 4 이후로 미룬다. 지금은 거부 사유와 허용 방법만 보여 준다 |
| D-6 | R-1 문서 갱신 담당 | `usage.md`·`README.md` 소유자에게 배정한다. 이 문서는 설계 문서만 소유한다 |

## 6. 확인하지 않은 것

- 실제 API 경로: 키가 있는 실행, 모델 오류 문구(404 등), 토큰 사용량 표시, 요청 시간.
- `npm link`와 전역 `codaryn` 명령. 다른 OS와 터미널(PowerShell 7, cmd, macOS, Linux).
- 취소(Ctrl+C, `--cancel-file`)와 재수정 반복의 진행 줄. 화면 낭독기, 좁은 터미널, 색 표시.
