### L-1 (낮음) Cc·Cf·공백 밖의 문자로 키 앞 38자 안에서 끊긴 키는 등록돼 있어도 빠져나간다 (main은 거부)

- **해당 문자**: 위 표의 굵은 줄. `--goal`, task 파일, 변수 파일로 등록한 키 모두에서 재현된다.
  - 보이지 않는데 Cf가 아닌 문자: 이체 선택자(BMP 안·밖), 결합 자소 연결자, 한글 채움 문자, 점자 빈칸
  - 보이는 문자: 역슬래시와 줄바꿈, 가운뎃점, HTML 문자 참조
  - task 파일의 짝 없는 대리 문자 이스케이프
- **결과**: 106자 중 끊긴 뒤 81자가 제공자 요청과 기록에 간다. R-25 M-1과 같은 결과이고, main은 넓은 모양(접두사 뒤 8자)으로 거부했다.
- **원인**
  - 등록 값 비교(`createKeyValueCheck`)와 모양 검사는 `KEY_SEPARATOR_PATTERN_SOURCE`(`[\s\p{Cc}\p{Cf}]`)만 뺀다.
  - 이체 선택자·결합 자소 연결자는 Mn, 한글 채움 문자는 Lo, 점자 빈칸은 So다.
  - DR-40 (a)의 "보이지 않는 문자(영폭 공백, soft hyphen 등)"에는 앞의 넷도 든다고 본다.
- **낮음으로 두는 까닭**: R-25의 입력(줄바꿈, 영폭 공백, soft hyphen, NBSP 등 복사·붙여넣기에서 흔한 것)은 모두 막혔다. 남은 문자는 키 안에 들어갈 일이 드물다.
- **제안** (계약 w3:p9). 실험(`exp/candidates.mjs`)으로 확인했다.
  - 등록 값 비교를 글자와 숫자만 남긴 글에서도 한다. 글과 값 모두에서 `[A-Za-z0-9]` 밖의 문자를 모두 빼고 포함 여부를 본다.
  - 위의 굵은 줄 가운데 등록된 경우를 모두 잡는다. HTML 문자 참조만 못 잡는다: 참조 안의 숫자가 이어짐을 끊는다.
  - 등록 값은 16자 이상의 무작위 값이라 오탐 걱정이 거의 없다.
  - 미등록(U1)은 DR-40의 "남은 놓침"과 같은 부류로 둔다.

### L-2 (낮음) 공백까지 빼고 모양을 보는 탓에, main과 `pm/bundle-3`이 받던 평범한 글이 거부된다

- **원인**: `holdsRefusedKeyShape`는 `compactKeyText`(공백 포함)를 뺀 글에서 모양을 다시 본다. 그래서 단어들이 이어 붙는다.
  - `sk-`가 글 처음이나 문장부호 뒤에 있으면 단어 시작이 된다.
  - OpenAI 모양은 그 뒤만 본다: 접두형은 20자 이상, 옛 형식은 대문자·소문자·숫자가 섞인 영숫자 40자 이상.

- **실제로 걸릴 만한 경우**: 지역화 작업에서 흔한 로캘 코드(`sk-`+`SK`)로 시작하는 goal이 있다(F1, F2). `sk-`+`admin`, `sk-`+`proj`로 시작하는 패키지 이름도 그렇다(F3).
- **DR-36 (c)와의 관계**: Anthropic 접두사가 붙은 이름이 문장부호 뒤에 오거나 목록에 있으면 다시 거부된다. main과 같은 상태로 돌아간 것이고, DR-36 (c)가 줄인 오탐(R-20 F)이 일부 되살아났다.
- **계약 주석과의 차이**: 주석(`src/contracts/keys.ts`의 `holdsRefusedKeyShape`)은 Anthropic 접두사가 붙은 이름의 경우와 "R-20 이름 14개, 한 줄에 하나 또는 한 줄에 이어서"만 적었다. 글머리표·번호 목록과 OpenAI 모양의 오탐은 적지 않았다.
- **낮음으로 두는 까닭**: 안전한 쪽(거부)이고, 사람이 문장을 바꾸면 피할 수 있다.
- **제안** (계약 w3:p9). 실험(`exp/candidates.mjs`)으로 확인했다.
  - 모양을 다시 볼 때는 보이지 않는 문자와 줄바꿈만 뺀다: Cc(탭·LF·CR 포함), Cf, U+2028·U+2029. 보이는 공백(Zs)은 남긴다.

## 4. 시간과 크기 상한

**검사 시간** (`exp/time-b3b.mjs`, 등록 키 하나, `goalHoldsKey`와 파일 글 검사 `rawTextHoldsKey`)

| 공격 글 | 256 KiB | 1 MiB |
|---|---|---|
| 접두사 반복(R-25 L-2) | 4 / 6 ms (`pm/bundle-3`은 6,694 / 13,497 ms) | 12 / 13 ms |
| 접두사와 공백 | 5 / 9 ms | 15 / 28 ms |
| 접두사와 영폭 공백 | 7 / 13 ms | 25 / 35 ms |
| OpenAI 접두형, 19자 뒤 마침표 | 2 / 4 ms | 6 / 12 ms |
| OpenAI 옛 형식 시작, 39자 뒤 하이픈 | 3 / 5 ms | 8 / 17 ms |
| 영폭 공백만 | 2 / 6 ms | 7 / 14 ms |
| 글자와 영폭 공백 | 9 / 16 ms | 27 / 65 ms |
| 옛 형식 시작과 띄운 글자 | 5 / 9 ms | 16 / 35 ms |

**크기 상한** (`exp/cap-cli.mjs`, 실제 CLI). 시험한 경로: `run --task`, `run --config`, `doctor --task`, `doctor --config`, `models --config`.

| 파일 | 결과 |
|---|---|
| 정확히 1,048,576바이트 | 받아서 다음 단계로 간다(`invalid_task`·`invalid_config`의 JSON 오류, 155~224 ms) |
| 1,048,577바이트 | 거부 |
| 1,048,575바이트 + 2바이트 글자(글자 수로는 1,048,576) | 거부: 바이트로 센다 |
| 바이트 순서 표시 + 1 MiB | 받는다: 표시는 빼고 센다 |
| 64 MiB | 거부, 104~157 ms |

- 넘을 때의 문구는 `the task file is larger than 1048576 bytes (1 MiB); nothing in it was used`다. 설정 파일은 `the config file …`이고, doctor는 항목의 `fail` 문구로 같은 말을 한다.
- 출력 어디에도 파일 내용(표지로 넣은 접두사)이 없었다.

### I-1 (정보) GUI 설정 읽기(`src/app/settings.ts`)에는 1 MiB 상한이 없다

- 검사는 이제 선형이라 멈춤은 없다(1 MiB 65 ms 이하). 남는 것은 메모리와 CLI와의 일관성뿐이다.
- CLI도 파일 전체를 읽은 뒤 크기를 본다(64 MiB를 157 ms에 거부).
- 계약 상수가 나오면 앱 계층에도 같은 상한을 두기를 권한다(앱 w3:pA).

## 5. 가림과 고정 값 (`exp/hide-diff.mjs`, `exp/pin-diff.mjs`)

- **가림 모양**
  - `ANTHROPIC_KEY_PATTERN_SOURCE`(넓은 모양)는 `pm/bundle-3`과 같다.
  - `API_KEY_MASK_PATTERN_SOURCES`는 `pm/bundle-3`의 4개를 그대로 담고, 형식 갈래(44자 원문) 하나를 더해 5개다.
  - 형식 갈래가 맞는 범위는 넓은 모양이 이미 가린다.
- **가림 결과**: 실제 형식 키를 무작위로 끊고 앞에 글자를 붙인 입력 3,000개로 비교했다. `pm/bundle-3b`가 `pm/bundle-3`보다 키를 더 보인 경우는 셋 모두 0건이다.

  | 가림 함수 | 더 보인 경우 | 덜 보인 경우 |
  |---|---|---|
  | CLI `hideKeys` | 0 | 1,205(등록) / 788(미등록) |
  | i18n `cleanLine` | 0 | 0 |
  | 모델 redactor | 0 | 0 |

  모델 redactor는 영폭 공백·soft hyphen·U+E0041로 끊긴 키도 남김없이 가렸다.
- **SP-0 고정 값**: `pm/bundle-3`과 잎 단위로 같다(바뀜·추가·삭제 0). 고정 시험 10/10이 통과했다.
- **DR-40 시험**: 4개 파일, 64/64 통과. L-1의 문자들(U+FE0F 등)은 이 시험에 없다.

## PM 질문

1. **L-2.** 모양을 다시 볼 때 보이는 공백을 남길지(오탐 제거, 미등록 키가 스페이스·NBSP로 끊기면 놓침), 지금처럼 뺄지(로캘 코드·`sk-`+`admin` 이름 등 오탐) 정해야 한다.
   - 가정: 남긴다. 등록 값 비교는 모든 공백을 빼고 하므로, 등록된 키는 공백으로 끊겨도 잡힌다.
