## 2. 남은 것(건수에 넣지 않음, 참고)

- **`plan --json`의 summary는 `safeModelText`를 거치지 않는다.** 짧은 가릴 값을 ZWSP로 나눈 summary가 `plan --json`(과 앱 계층의 plan 출력)에 `R52<ZWSP>pass`로 남는다. 정확한 값은 아니지만, ZWSP는 보이지 않으므로 그 JSON을 그대로 보이는 화면에서는 값처럼 읽힌다.
  - main `b2dad78`도 JSON이 같다. main의 계획 보기는 ZWSP를 그대로 찍었는데(값처럼 보임), 이 판의 계획 보기는 `R52?pass`로 보인다. 그러니 이 판에서 나빠진 것은 없다.
  - 게이트웨이가 16 코드 포인트보다 짧은 값을 나뉜 꼴로 찾지 않는 것은 문서화된 규칙이다. GUI의 계획 화면은 summary를 보이지 않는다.
  - 마지막 답과 같게 하려면 `planSummary`(`src/cli/plan-commands.ts`)도 `safeModelText`로 만들면 된다.
- **journal은 예전처럼 모델 답의 원문을 남긴다.** 나뉜 키, 짧은 값의 나뉜 꼴, 키 모양 원문이 `model_response.text`에 있다(R52-I1, main과 같다).
- R-52의 정보 항목 가운데 결합 문자(U+034F)로 나뉜 값(R52-I2)과 답 뒤에 끝난 실행의 마지막 답(R52-I3)은 그대로다.
