## 요약: 사용자에게 물을 것

다음 다섯 가지는 사용자의 지침 파일이나 사용자 확정 행이라 PM이 고칠 수 없다.

1. **현재 단계:** CLAUDE.md·AGENTS.md의 "현재 단계는 1a"를 지금 상태(단계 1~5의 오프라인 구현이 진행 중)로 바꿀지(A-1~A-3, A-6).
2. **실제 API 호출:** 같은 줄의 "실제 API 호출은 하지 않는다"를 규칙으로 따로 남길지, 실제 점검(`tests/live`)을 언제 허락할지(A-1, A-3).
3. **VS Code:** AGENTS.md 개발 순서 5번과 사용자 확정 행 U-2·U-21의 "VS Code"를 DR-20(만들지 않음)에 맞춰 뺄지(A-2, A-7).
4. **두 번째 제공자:** AGENTS.md의 제공자 줄에 OpenAI(DR-31)를 적을지(A-4).
5. **위임 범위:** `docs/pm-control.json`의 `scope`(`phase-1a-offline-cli`)를 지금 범위로 바꿀지(A-6).

B·C·D의 문서 항목은 PM이 담당에게 배정하면 고칠 수 있다.
