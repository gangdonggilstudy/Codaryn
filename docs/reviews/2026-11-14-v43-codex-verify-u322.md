첫 실행은 Windows 경로를 JSON 문자열 전체에서 치환한 오류로 일부 요청이 **자기 이전 비봉인 물리 fixture**를 가리켰고 일부 파일/원복 기록이 다시 처리됐다. **전부 폐기했으며 어떤 통과 건수에도 포함하지 않았다.** 원시 증거는 replay/와 replay.log에 보존했다.

- `.worktrees/codex-verify/.codaryn/codex-sec-v43-baseline/baseline-v2/<사례>/ws/`의 비봉인 물리 fixture.
- `.worktrees/codex-verify/.codaryn/codex-sec-v43/replay/<사례>/`의 첫 재생본·증거.
