## PrivacyGateway와 출력 경계

실제 `src/contracts/privacy.ts:17–19,58–63`의 mask 반환은 성공 MaskedText 또는 masking_failed다. `src/privacy/index.ts:344–350`도 scan 예외를 잡아 masking_failed로 돌려준다. 동결 port의 정상/실패 반환 모양은 이 계약과 같다. 원래 throw 사례는 외부 port 예외 주입이며 실제 gateway가 정상 입력에서 던진다는 증거가 아니다. 그대로 전파되는 sentinel 동일성은 재생에 보존됐다.

## 실패한 검증 도구 호출과 명령

첫 `types` 호출은 파일 인자와 상위 tsconfig 동시 발견에 따른 TS5112로 exit1이었다. 두 번째 `types-final`은 --ignoreConfig를 사용했지만 명시적인 types:node가 없어 Node ambient 이름 미해결과 파생 TS2591/TS2503/TS7006/TS2552로 exit1이었다. 둘 다 성공으로 세지 않았다. 로그와 command JSON을 그대로 보존했다.

마지막 증거 조회 한 번은 main cwd에서 상대 로그 경로 두 개를 사용해 파일 없음 메시지를 냈다. 실제 감사 폴더에서 다시 읽어 확인했으며 추가 시험 성공이나 실패로 계상하지 않았다.

핵심 실행 명령은 `git archive --format=tar --output=<own>/candidate.tar HEAD`, 자기 source로 tar 추출, `node run.mjs setup`, `node run.mjs replay`, `node run.mjs bindings`, `node run.mjs types-config`, `node run.mjs tests`, `node run.mjs baseline-final`이다. setup은 read-only Git 대조와 `npm.cmd ci --offline --ignore-scripts`, `npm.cmd run build`를 수행한다. 각 실제 argv/cwd/exit/기간은 command-*.json에 있다. 관련 시험의 정확한 11파일은 command-related-tests.json에 있으며 plan/changes/apply/summary mask/DR-28/error/approval/old export 경계를 포함한다.
