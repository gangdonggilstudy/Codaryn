# 사용성 개선 작업 지시

사용자가 2026-11-12에 "편의성도 확보하게 설계하고, 설계 전문가를 다시 붙여 사용성 개선을 협의해 추가 설계하고, UX 설계도 진행하고, 모두 문서화하라"고 지시했다. p6(수석 아키텍트 겸 UX 설계)이 [사용성 검토](../design/usability-review.md)와 [UX 설계](../design/ux-design.md)를 작성했고, 그 "결정 필요" 항목을 임시 PM(w1:p3)이 아래와 같이 정했다. 사용자는 추가 지시가 없으면 끝까지 연속 진행하라고 했으므로 PM이 정하고 근거를 남긴다.

기준은 main `c8c0d9b`다(유닛 722건 중 721 통과·1 건너뜀, 통합 343건 통과. 통합 전체 4회 중 1회 간헐 실패가 있어 조사 중이다. 실제 API 미실행).
