# 키 없이 체험하기: 자료 분석 (분석 → 검증 → 재수정 → 사람 확인)

API 키 없이 `analyze` 작업 종류의 흐름을 보는 예시다.

- 모델 대신 정해진 대본(scripted 모델)이 표를 읽고 결과 표와 보고서를 쓴다.
- 처음 결과 표에는 일부러 틀린 합계 하나가 있다. `data_checks` 검증기가 그것을 찾고, 재수정 한 번으로 고친다.
- 검증을 통과해도 `done`이 되지 않는다. 사람이 결과를 보고 `review`로 판정을 기록한다.

| 파일 | 내용 |
| --- | --- |
| `task.json` | 작업 정의. `workflowRef: "analyze"`. 원본 표 `sales.csv`는 보호 경로다. 재수정 1회. 검증기는 `data_checks`(결과 표의 열·행 수와 지역별 합계)와 `file_rules`(보고서) 둘이다 |
| `script.json` | 모델 대신 응답하는 대본. 표를 읽고, `summary.csv`(east 합계가 틀림)와 `report.md`를 만들고, 재수정에서 `summary.csv`를 고친다 |
| `workspace/sales.csv` | 합성 판매 표(지역, 품목, 금액) 여섯 줄. 사람이나 연락처 같은 값은 없다 |

실행 방법과 출력은 [사용 안내 18.9절](../../docs/usage.md#189-키-없이-체험하기-자료-분석)에 있다.

- 순서는 `doctor` → `run` → `report` → `review --accept` → `runs`다.
- 이 폴더를 그대로 실행하지 말고 저장소 밖으로 복사해서 실행한다. 저장소 안에서는 `workspace_is_install_dir`로 거부된다.
- 키도 설정 파일도 필요 없다.
- 자료 분석은 표의 행을 그대로 모델에 보낸다. 실제 모델로 돌릴 때도 개인정보가 든 표는 쓰지 않는다([사용 안내 18.7절](../../docs/usage.md#187-개인정보가-든-자료는-다루지-않는다)).
